# Templates

**Reusable forms for common governance needs.**

---

## Available Templates

| Template | Use When |
|----------|----------|
| [Project Proposal](project-proposal.md) | Proposing a new initiative, event, or program |
| [Project Closure](project-closure.md) | Closing out a completed project |
| [Board Resolution](board-resolution.md) | Formalizing significant board decisions |
| [Technology Proposal](technology-proposal.md) | Proposing new systems or tools |

---

## How to Use Templates

1. **Copy** the template to your document
2. **Fill in** all sections (don't skip any)
3. **Submit** to the appropriate committee or channel
4. **Revise** based on feedback
5. **Archive** the final version when complete

---

## Template Philosophy

Good templates:
- **Guide** without constraining
- **Capture** essential information
- **Enable** fair comparison between proposals
- **Document** decisions for the future

If a template doesn't fit your need, propose changes to it!
