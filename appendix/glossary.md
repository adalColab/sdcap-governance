# Glossary

**Terms and acronyms used in SDCoLab governance.**

---

## Organizations

| Term | Definition |
|------|------------|
| **SDCAP** | San Diego Collaborative Arts Project — the 501(c)(3) nonprofit |
| **SDCoLab** | San Diego Collaborative Lab — the makerspace |
| **Burning Man Project** | The parent organization of Burning Man, based in San Francisco |

---

## Governance Terms

| Term | Definition |
|------|------------|
| **Async Decision** | A board decision made outside of a formal meeting, via electronic communication |
| **Board** | The Board of Directors, the legal governing body of SDCAP |
| **Bylaw** | The fundamental rules governing the organization |
| **Committee** | A group assigned to handle specific areas of work |
| **Consent Agenda** | A bundle of routine items approved together without individual discussion |
| **Executive Session** | A closed portion of a meeting for sensitive matters |
| **Fiscal Sponsorship** | When SDCAP serves as the 501(c)(3) for another project |
| **Motion** | A formal proposal for board action |
| **Quorum** | The minimum number of members required to conduct business |
| **Resolution** | A formal decision documented in a specific format |
| **Robert's Rules** | Parliamentary procedure guidelines we loosely follow |

---

## Fire Triangle

| Term | Definition |
|------|------------|
| **Fire Triangle** | Our organizational model: Fuel + Oxygen + Heat = Fire |
| **FUEL (🟡)** | SDCoLab — material resources, space, tools |
| **OXYGEN (🔵)** | SDCAP — enablement, logistics, information |
| **HEAT (🔴)** | Community — energy, participation, giving |

---

## Technology Terms

| Term | Definition |
|------|------------|
| **ERPNext** | Open-source ERP (Enterprise Resource Planning) system |
| **Frappe** | The framework ERPNext is built on |
| **Discourse** | Open-source forum software |
| **Discord** | Real-time chat platform (used by our community) |
| **QGIV** | Donation processing platform |
| **Bloomerang** | Donor management platform |
| **Self-hosted** | Running software on our own servers |
| **SaaS** | Software as a Service — hosted by the vendor |

---

## Process Terms

| Term | Definition |
|------|------------|
| **Introduce → Parallel → Transition** | Our three-phase approach to technology adoption |
| **Pilot** | A limited test of a new system or process |
| **Parallel** | Running new and old systems simultaneously |
| **Steward** | The person responsible for ongoing ownership of a system |
| **Sunset** | Retiring a system or process |

---

## Burning Man Terms

| Term | Definition |
|------|------------|
| **10 Principles** | The guiding values of Burning Man culture |
| **Burn / The Burn** | Burning Man event, or similar regional event |
| **Regional** | A Burning Man-affiliated event outside Black Rock City |
| **Theme Camp** | A group that creates an interactive space at Burning Man |
| **Art Car / Mutant Vehicle** | A decorated vehicle licensed for the playa |
| **Playa** | The Black Rock Desert; also used generically for event venue |
| **MOOP** | Matter Out Of Place — trash/debris |
| **LNT** | Leave No Trace |
| **DPW** | Department of Public Works |
| **Ranger** | Black Rock Ranger — community mediation volunteers |

---

## Financial Terms

| Term | Definition |
|------|------------|
| **501(c)(3)** | IRS tax-exempt status for charitable organizations |
| **990** | Annual tax return filed by nonprofits |
| **Grant** | Money given to support a specific project |
| **Fiscal Year** | Our accounting year (typically calendar year) |
| **In-kind** | Non-cash contributions (materials, services, space) |
| **Restricted Funds** | Money designated for a specific purpose |
| **Unrestricted Funds** | Money that can be used for general operations |
