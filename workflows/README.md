## The Core Pattern: Sense → Stabilize → Strengthen

All workflows share this maturation pattern:

```
SENSE          →   STABILIZE      →   STRENGTHEN
Discover shape     Bound scope        Ship & document
Gather signals     Pick owners        Automate & teach
Name the real      Reduce wobble      Hand off cleanly
```

Work moves left to right. If something wobbles, it moves back left to re-stabilize.
