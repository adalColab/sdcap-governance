# SDCoLab Engagement Process

**How to work with the makerspace.**

---

## What is SDCoLab?

**San Diego Collaborative Lab** is the physical makerspace that provides:
- Workshop space
- Tools and equipment
- Materials and supplies
- Hands-on expertise
- Build sessions and classes

SDCoLab is the **FUEL** in our Fire Triangle — the material resources that make art possible.

---

## What Can SDCoLab Help With?

| Need | What We Offer |
|------|---------------|
| **Build space** | Workshop access for art projects |
| **Tools** | Power tools, hand tools, specialty equipment |
| **Materials** | Scrap/surplus materials, group buys |
| **Knowledge** | Build expertise, technique classes |
| **Labor** | Build party participation |
| **Storage** | Limited project storage during active builds |

## How to Access the Space

### Drop-In (Public Events)

1. Check the calendar for open events
2. Show up
3. Sign the waiver (first time)
4. Follow safety rules
5. Clean up after yourself

**No advance arrangement needed.**

---

### Membership

**What you get:**
- Scheduled workshop access
- Tool checkout privileges
- Member storage locker
- Voting rights (after 3 months)
- Discount on classes

**Requirements:**
- Complete orientation
- Pass safety certification for each tool area
- Pay monthly dues
- Follow all policies

**Process:**
1. Attend orientation session
2. Complete safety certifications (as needed)
3. Sign membership agreement
4. Set up dues payment
5. Get your access credentials

---

### Project Residency

For larger projects that need dedicated space:

**Requirements:**
- Active member in good standing
- Defined project with timeline
- Budget for any materials/consumables
- Commitment to leave-no-trace
- Weekly check-in/progress

**Process:**
1. Submit residency application
2. Space Committee reviews
3. Site visit and space allocation
4. Sign residency agreement
5. Begin work
6. Weekly progress updates
7. Clean exit at end of residency

**Duration:** Typically 1-3 months, renewable

## Tool Library

### Categories

| Category | Examples | Certification |
|----------|----------|---------------|
| **Hand Tools** | Hammers, saws, wrenches | None |
| **Power Tools - Basic** | Drills, sanders, jigsaws | Basic cert |
| **Power Tools - Advanced** | Table saw, miter saw | Advanced cert |
| **Welding** | MIG, TIG, stick | Welding cert |
| **CNC/Laser** | CNC router, laser cutter | Specialty cert |
| **Sewing/Textiles** | Sewing machines, sergers | Basic cert |

### Checkout Rules

1. Check availability in tool library system
2. Reserve if needed
3. Inspect tool at checkout
4. Return clean and functional
5. Report any damage immediately
6. Late returns = suspension of privileges

### Certification Process

1. Sign up for certification class
2. Complete classroom portion
3. Demonstrate safe operation
4. Pass written quiz
5. Certification added to your profile

## Safety Requirements

### Universal Rules
- No working alone on power tools
- Closed-toe shoes required
- Safety glasses in shop areas
- No alcohol/drugs before or during work
- Clean as you go

### Tool-Specific Safety
- Follow posted procedures for each tool
- Use required PPE (posted at each station)
- Don't use tools you're not certified for
- Ask if you're unsure

### Incident Reporting
- All injuries reported immediately
- Near-misses reported (helps us prevent real injuries)
- No blame culture — we learn from incidents
- First aid kit locations posted

## Materials

### What's Available
- Scrap pile (free, take what you need)
- Surplus materials (low cost)
- Group buy materials (at cost)
- Consumables (blades, sandpaper, etc.)

### Material Donations
We accept:
- Clean, usable materials
- Working tools
- Shop supplies

We don't accept:
- Garbage disguised as donations
- Hazardous materials
- Things we don't have space for

### Purchasing
- Order through group buys when possible
- Reimburse for project materials (with prior approval)
- Keep receipts for everything

---

## Storage

### Member Lockers
- One locker per member
- Must fit in assigned space
- No hazardous materials
- Clean out if membership lapses

### Project Storage
- Applied for as part of residency
- Time-limited (project duration)
- Labeled with name, project, end date
- Forfeit if abandoned

### No Storage
- Personal belongings outside designated areas
- Long-term storage without arrangement
- Abandoned projects

---

## Scheduling

### Workshop Access
- Book via online calendar
- 4-hour blocks maximum (can extend if available)
- Cancel if you can't make it
- No-shows may lose booking privileges

### Equipment Reservations
- High-demand tools require reservation
- Book up to 2 weeks in advance
- 2-hour blocks for popular tools
- Be on time or lose slot

---

## Community Guidelines

### Do:
- Leave it better than you found it
- Help newcomers
- Share knowledge freely
- Communicate proactively
- Report issues (tools, safety, interpersonal)

### Don't:
- Gatekeep knowledge or access
- Leave messes for others
- Use equipment you're not certified for
- Ignore safety rules
- Be a jerk
